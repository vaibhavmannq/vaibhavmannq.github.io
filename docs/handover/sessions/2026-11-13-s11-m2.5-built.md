## Learned

  is asleep (wake it: `adb shell input keyevent KEYCODE_WAKEUP`), and `pages()[0]` can be a blank new tab:
  `phone.mjs` now picks the open `localhost:4181` tab.
- A preview server already on 4181/4173 is reused; after `npm run build` it serves the new files, but a failed
  build leaves the old bundle (the e2e then tests stale code). Check the build log's last line.
- Headless e2e frames stall for seconds while new views compile: poll for an outcome, never a fixed wait.
- GPU `cos`/`sin` are imprecise near tiny angles: compare squared angles.
