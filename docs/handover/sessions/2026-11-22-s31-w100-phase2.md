## Learned
- TaskStop on a Windows background job does not kill its children: a stopped probe script kept riding the phone and
  heated it. Kill by command line (`Get-CimInstance Win32_Process … | Stop-Process`).
- `netcheck` order matters: the first page in a fresh Chrome is ~2 s slower; measure both orders.
- three r186 `DataArrayTexture.addLayerUpdate` uploads only the listed layers, even on the first upload: clear the
  layer updates before `initTexture` or the other layers are never uploaded.
- TSL's `If` must be built inside an `Fn`: outside one the whole world failed to start. Load one page and read the
  console after every shader edit, before any measuring.
- A cost "measured at one place" is not the cost: the drift's +0.1 ms at Golden was +1.7 at Before dawn, because other
  parts read the sky too (memory: speed verdicts need the whole sweep).
- The phone at its frame budget hides single costs: probe the sum (everything off) before ruling pieces out.
- Low memory kills background runs on this laptop (~1.9 GB free with the owner's apps): one test browser, short runs.
- An 8-bit sky photo's own mips give a cheap low-pass: the drift keeps the glow by multiplying the moved photo by
  mip(here) / mip(there).
