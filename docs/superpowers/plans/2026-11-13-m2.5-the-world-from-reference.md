# M2.5, the World from Reference Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One pass over the whole world that makes it obey real references: a world state per place that every
moving part reads, stacks and a lopsided arch that follow how real basalt coasts erode, tide bands and coloured
shadows on every rock, glitter roads on the water and a real moon, look-around everywhere, and Golden's first near
layer and spots; each judged against the owner's photos with a % for look and a % for behaviour.

**Architecture:** Land shapes stay in `tools/world/blender/coast.py` (the source of truth since M1) and are baked
as before (`npm run world`); the arch is exported from Blender once, like the cave (`npm run world:blender`). Light
and water changes are shader edits in the existing parts. The world state is new fields on the hour presets,
exported by `tools/world/export_hours.py` and blended like every other field. Interaction (look-around, spots)
lives in `src/journey/` as pure functions with a thin wiring in `src/app/boot.ts`, as pace and parallax did in s09.

**Tech Stack:** TypeScript + three.js 0.186 (`three/webgpu`, `three/tsl`), Vitest, Playwright; Python 3 + numpy
(world tools); Blender 5.2 for the arch export; adb + Chrome remote debugging for the phone.

**Spec:** `docs/superpowers/specs/2026-11-10-realtime-world-design.md` as amended by
`docs/superpowers/specs/2026-11-11-world-design-amendment-1.md` (§3, §4 row I, §6, §10 M2.5). Look authority:
`docs/handover/research/owner-references.md` (D28); behaviour and numbers: `docs/handover/research/reference-book.md`
(D24); rock rules: `docs/handover/research/reference-landforms.md` §2; world changes:
`docs/handover/research/design-review-and-proposals.md` §3. Before any three.js code: `research/threejs-r186-notes.md`.

## Global Constraints

- Speed bar (D9): name < 1 s, first view < 3 s at 10 Mbit/s, 60 fps at stops on the default tier, ≥ 55 in flight, no
  frame over 50 ms; ≈ 3 MB per stop. JavaScript ≤ 400 kB gzip (now 275 kB); world base ≤ 1.0 MB.
- Census (D13): ≤ 60 draws including the mirror pass, ≤ 14 materials, ≤ 2.5 M triangles at every stop.
- Every part that is not in play is `visible = false`. Per pixel only what must be sharp; slow terms per vertex
  (s09: the cave went 11.5 → 2.6 ms this way). No branch on a uniform outside a TSL `Fn` (s09: broke stage B).
- Every constant that drives motion or colour cites its line in `reference-book.md` or a numbered owner photo.
- Every changed view is shown beside the old one (`npm run compare`), with a switch back where it is an option.
- coast.py stays runnable in Blender and importable without it; Blender runs use `--python-exit-code 1`.
- No new npm dependencies. Commit on `world`; never push without asking; no AI attribution in commits.
- D15: I judge every piece (likes, dislikes, look %, behaviour %) before the owner tests anything.

## Review Focus

1. **A rock moved by the re-scatter now stands in a protected camera view or a flight path** (D16 views, the
   flights' clearance). Test in Task 3: `npm run world:test` green and the flight clearance test unchanged.
2. **Look-around and parallax fight a flight** (the head is turned when the scroll starts): the turn must ease
   back to the path, never snap. Test in Task 6: `lookOffset` decays to 0 within 1.2 s once `resting` is false.
3. **Touch drag scrolls the page instead of turning the head**, or turning blocks scrolling. Test in Task 6
   (e2e, mobile viewport): a horizontal drag turns the head and leaves `scrollY` unchanged; a vertical one scrolls.
4. **Glitter shimmers far away** (sub-pixel sparkles flicker). Test in Task 5: the glitter term is faded where one
   facet is under two pixels (`fwidth`), checked on a 412×915 frame at Golden and Sunset.
5. **A spot's walk path enters rock or the sea** (Golden's spots are hand-placed). Test in Task 7: every sample of
   every baked spot path stays ≥ 0.4 m above `max(ground, 0)`.
